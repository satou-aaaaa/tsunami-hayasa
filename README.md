# 津波の速さくらべ（tsunami-hayasa）

海の深さ（水深）から津波の速さを出し、歩く人・車・新幹線・ジェット機などとどちらが速いかを当てる1日5問の学習ゲーム。正解したら、その津波が100mを何秒で進むかも選ぶ。答えのあとに、深さと速さの物差しが出る。岸の近くの水深10mでも時速約36km、100mを約10秒。

遊ぶ: <https://satou-aaaaa.github.io/tsunami-hayasa/>

- 津波の速さは、静岡県「津波について」<https://www.pref.shizuoka.jp/bosaikinkyu/sonae/1040807/1030065.html> の式 √(9.8×水深) で出した目安です。名古屋市・気象庁の「水深10mで時速約36km・5000mで約800km」と合います。本物の津波は、海底や海岸の地形などで速さが変わります。
- くらべる相手の速さは、消防庁の報告書（歩く速さの目安）・道路の法定速度・気象庁のリーフレットのたとえから取りました。出典はゲームの「このゲームについて」にあります。
- 記録は遊ぶ人のブラウザだけに残り、外へ送りません。結果の「共有」を押したときだけ、その日の回の番号と各問の○×の並びが、選んだサービス（X・LINE など）に渡ります。
